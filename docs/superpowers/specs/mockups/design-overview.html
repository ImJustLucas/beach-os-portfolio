L'arrivée (l'effet wow)

Écran noir → séquence de boot « BEACH-OS v1.0 » façon BIOS avec sons chiptune → flash d'allumage télé → le bureau se révèle avec le coucher de soleil et la vague sonore. Skippable d'un clic, joué une fois par session seulement.
