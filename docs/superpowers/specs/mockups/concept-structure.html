B — « Beach OS » complet

Tout le site est un bureau d'ordinateur rétro habillé plage : fond d'écran animé, fenêtres draggables pour chaque section (projets, bio, vidéos YT), dock avec icônes surf. Très joueur, très mémorable, montre tes skills front — mais demande plus de dev et le visiteur doit « explorer » pour trouver le contenu.

C — Hybride : plage immersive + fenêtres OS pour les projets

Le site est une one-page plage immersive (comme A), mais la section projets reprend le clin d'œil OS : chaque projet est une petite fenêtre rétro posée sur le sable, qu'on peut ouvrir. Le thème plage domine, l'idée OS survit en easter egg maîtrisé.

Clique sur une carte pour la sélectionner, puis dis-moi en terminal ce qui te fait vibrer (ou ce qui te refroidit) dans chacune.
